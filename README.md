# График смен

Простой сайт под iPhone для одного человека:

- красным отмечаются рабочие дни;
- зелёным отмечаются выходные;
- официальные праздники по России загружаются автоматически;
- все отметки сохраняются прямо в браузере, без сервера и без базы данных.

## Как запустить локально

Проще всего открыть папку на любом статическом сервере. Например:

```bash
python3 -m http.server 4173
```

После этого открыть в браузере:

```text
http://127.0.0.1:4173
```

## Как использовать на iPhone

1. Открой сайт в Safari.
2. Нажми `Поделиться`.
3. Выбери `На экран Домой`.
4. После этого сайт будет открываться почти как обычное приложение.
